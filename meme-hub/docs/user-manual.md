# คู่มือใช้งาน Meme Hub

## 1. เปิดหน้าเว็บ
เข้าที่ `http://localhost/meme-hub/` จะเห็นสถิติ มีมทั้งหมด และรายการมีมที่เผยแพร่แล้ว

## 2. ค้นหาและกรอง
กรอกคำค้นในช่อง “ค้นหามีมที่ใช่...” เพื่อค้นจากชื่อ คำบรรยาย หรือชื่อหมวดหมู่ เลือกหมวดหมู่จากรายการเพื่อกรองข้อมูล

## 3. เพิ่มมีม
กด “เพิ่มมีมใหม่” กรอกชื่อมีม คำบรรยาย ที่อยู่รูปภาพ หมวดหมู่ และผู้สร้าง เลือกสถานะเผยแพร่หรือฉบับร่าง จากนั้นกด “บันทึกมีม” รูปภาพใช้ได้ทั้ง `assets/memes/meme-default.svg` หรือ URL รูปภาพ `https://...`

## 4. แก้ไขมีม
กด “แก้ไข” บนการ์ดของมีมที่ต้องการ ปรับข้อมูล แล้วกด “บันทึกการแก้ไข”

## 5. ลบมีม
กด “ลบ” บนการ์ดและยืนยันการลบ ระบบจะลบข้อมูลจากฐานข้อมูล การลบไม่สามารถย้อนกลับได้

## 6. สถานะเผยแพร่
มีเฉพาะมีมที่มีสถานะ `published` เท่านั้นที่แสดงบนหน้าแรก มีมสถานะ `draft` จะยังไม่แสดงในรายการสาธารณะ
